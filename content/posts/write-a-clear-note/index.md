写学习笔记时，可以先确定一个具体问题，再围绕它组织解释与例子。

## 把问题写具体

与其只写一个宽泛的主题，不如先写下想回答的那句话。例如：“为什么循环执行了 n 次，却不一定意味着算法的时间复杂度是 O(n)？”

问题越具体，越容易判断笔记有没有把它解释清楚。

## 用一个小例子检验理解

下面两个循环虽然外层都执行 n 次，工作量却不同：

```python
# 每次循环做固定数量的工作
for i in range(n):
    print(i)

# 外层每次迭代，都再执行 n 次内层循环
for i in range(n):
    for j in range(n):
        print(i, j)
```

在把每次输出视为常数时间操作的简化模型下，前者执行 n 次输出，后者执行 n² 次输出。分析工作量时，还需要看每次迭代内部做了什么。

## 留下来源与未解决的问题

记录参考资料的标题、链接或页码，也保留暂时不确定的部分。这样，之后复习时就能区分已经解释清楚的结论和还需要查证的问题。

一份可复用的笔记，可以包含这四项：

1. 要回答的问题。
2. 自己整理的解释。
3. 一个完整的例子。
4. 参考来源与待确认事项。
